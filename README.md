# 大学课程学习资料

个人大学课程学习讲义库，按 **学期 → 课程 → 内容** 组织。每门课的笔记按统一的《大学专业课程学习笔记制作规范 V3.0》制作，同时交付 Word（公式可编辑）与 PDF 双版本，并提供网页端在线阅读。

## 目录结构

```
大学课程学习资料/
├── 大二上/                          ← 按学期组织，后续会有大二下、大三等
│   ├── 复变函数与数理方程/
│   │   ├── 笔记/                    ← 各讲学习讲义 Word + PDF（正式交付版）
│   │   └── 资料/                    ← 课堂照片、录音等原始资料（目前仅存本地）
│   ├── 信号与系统/                   ← 占位，讲义待整理入库
│   └── 基础物理学2/                  ← 占位，讲义待整理入库
├── 网站源/                          ← 在线阅读站点（MkDocs Material）的页面源
├── 工具/                            ← 讲义 Markdown 源稿 → 网页版 的转换脚本
└── mkdocs.yml                       ← 站点配置
```

## 在线阅读

- 网页版站点：https://yunbianmailang.github.io/university-course-materials/
- 站点源为 `网站源/` + `mkdocs.yml`，构建产物发布在 `gh-pages` 分支。
- 更新站点：改完 `网站源/` 后运行 `python -m mkdocs gh-deploy` 即可重新发布。
- 每讲页面顶部提供 PDF 在线阅读与 Word 下载链接。
- 仓库另预留了 GitHub Actions 自动部署工作流（`工具/deploy-pages.disabled.yml`）：
  当前 GitHub 令牌缺少 `workflow` 权限，暂以分支方式部署；之后运行
  `gh auth refresh -s workflow` 补权限，把该文件移回 `.github/workflows/deploy-pages.yml`
  提交推送，即可改为推送后自动部署。

## 笔记规范要点（V3.0）

- 三层结构：一页课堂核心速览 / 引导式学习正文 / 详细参考与拓展，末尾附课末核心知识回顾。
- 复变函数采用「数学逻辑与证明型」讲解策略：严格定义、定理条件、证明思路、关键推导不跳步。
- 宋体 12.5 磅正文、1.3 倍行距，深蓝标题蓝灰正文；【核心结论】【思路提示】【易错提醒】三类固定强调模块。
- 只保留教师课堂例题与正式作业，不设自编成套练习。
- 每讲同时交付同名 Word 与 PDF。

## 如何新增一讲

1. 把新讲的正式讲义 `复变函数与数理方程_第X讲_主题_学习讲义.docx/pdf` 放入对应课程 `笔记/`。
2. 在 `工具/转换网页版.py` 的 `LECTURES` 列表里登记该讲（源稿目录、课次文件夹、讲次号）。
3. 运行 `python 工具/转换网页版.py`，再在 `mkdocs.yml` 的 `nav` 里加一行。
4. 本地 `python -m mkdocs serve` 预览无误后提交推送，并运行 `python -m mkdocs gh-deploy` 更新在线站点。

## 相关约定

- 笔记制作规范：见原材料工作区 `学习/信号与系统/.制作/大学专业课程学习笔记制作规范 V3.0.md`（V3.0 为现行标准）。
- 各讲 Markdown 源稿保存在本地原材料区的 `.制作/` 目录，本仓库只存网页版生成结果。
- 课堂照片、录音等原始资料暂不上传（录音单文件超 GitHub 100MB 限制且体积大），只保存在本地。
