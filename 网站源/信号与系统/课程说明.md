# 信号与系统 · 课程说明

本课程以「解题引导型」策略讲解：**问题背景 → 核心概念 → 建立模型 → 数学推导 → 系统解释 → 典型应用**。讲义突出时域、频域、复频域之间的联系，总结普适的解题流程，并按当前题目补充电路先修知识（KCL/KVL、复阻抗、节点电压法等），不默认已学电路课。
