# 基础物理学2（光学） · 课程说明

本课程以「物理图像驱动型」策略讲解：**物理现象 → 实验装置 → 物理模型 → 模型假设 → 数学推导 → 物理解释 → 实际应用**。先建立物理图像再引入数学表达，重要光路图与公式一一对应，傍轴近似等条件明确交代。以教师当讲课件为主线，以赵凯华、钟锡华《光学》为教材补充。

## 讲义总览

七讲均为规范 V3.0 版式，同时交付 Word 与 PDF（`基础物理学2_第X讲_主题_学习讲义.docx/pdf`）：

| 讲次 | 主题 | 内容要点 |
|---|---|---|
| [第1讲](第1讲_几何光学简介.md) | 几何光学简介 | 反射与折射定律、费马原理、傍轴成像、球面与薄透镜 |
| [第2讲](第2讲_波动光学基本原理（一）.md) | 波动光学基本原理（一） | 波前与光程、相干叠加、杨氏干涉 |
| [第3讲](第3讲_光的干涉与时空相干性.md) | 光的干涉与时空相干性 | 干涉装置、时间相干与空间相干 |
| [第4讲](第4讲_光的衍射与分辨本领.md) | 光的衍射与分辨本领 | 菲涅耳衍射、夫琅禾费衍射、圆孔衍射与分辨判据 |
| [第5讲](第5讲_衍射光栅与晶体衍射.md) | 衍射光栅与晶体衍射 | 光栅方程、色散与分辨本领、X 射线晶体衍射 |
| [第6讲](第6讲_偏振态与菲涅耳公式.md) | 偏振态与菲涅耳公式 | 偏振态表示、菲涅耳公式、布儒斯特角 |
| [第7讲](第7讲_双折射与偏振光应用.md) | 双折射与偏振光应用 | 双折射、波片、偏振光的干涉与应用 |
