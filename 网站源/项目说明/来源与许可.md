# 来源与许可

本项目是个人整理、持续修订的课程学习资料。讲义中的学习标识是阅读建议，课程要求和考试安排以教师通知为准。

## 来源如何区分

| 标记或图注 | 含义 |
|---|---|
| PPT重点、资料内容、资料例题 | 依据教师课件、板书或课堂例题整理，正文保留已有页码与位置 |
| 教材补充 | 根据已核对的教材补充；不把自主解释写成教材原文 |
| 理解补充、补充讲解 | 为理解而增加的重述、推演或示例 |
| 原图、教师原图 | 来源于教师资料，原权利归属保留 |
| 重绘 | 为讲解重新绘制；引用的构图、题目与内容仍按其来源说明 |
| 资料校核 | 指出原材料中的疑点、适用条件及核对依据 |

光学讲义以教师课件为主线，以赵凯华、钟锡华《光学》相关内容为补充；其他课程的资料名、页码和录音核对信息以各讲正文的实际标记为准。没有核对的出处不补写成已确认来源。
