# 笔记规范 V3.0

目标是帮助读者理解概念、掌握方法和建立课程联系。优先级为：**内容准确性 ＞ 知识理解效果 ＞ 结构清晰度 ＞ 阅读舒适度 ＞ 装饰美观**。

## 三层阅读结构

1. **课堂核心速览**：核心问题、必要先修、知识结构、重要公式与条件、听讲重点。
2. **引导式学习正文**：问题导入、直观理解、严格定义、关键推导、教师课堂例题与易错提醒。
3. **详细参考与拓展**：完整证明、较长推导和必要补充；保留课末核心知识回顾。

保留教师例题和正式作业，不另编成套自测题与答案。必要的简短示例用于解释概念。

## 各课程的侧重点

| 课程 | 讲解主线 | 核对重点 |
|---|---|---|
| 复变函数与数理方程 | 动机 → 定义 → 条件 → 证明思路 → 推导 → 应用 | 路径方向、奇点、收敛域、分支与定理前提 |
| 信号与系统 | 问题 → 模型 → 推导 → 系统解释 → 应用 | 零状态与初态、ROC、因果稳定、频率单位和变换约定 |
| 基础物理学2（光学） | 现象 → 装置 → 模型 → 假设 → 推导 → 解释 | 光路与波面、符号、近似条件、振幅与强度、图式对应 |

## 固定标记

- **核心结论**：定义、定理、公式及必要条件。
- **思路提示**：先修知识、直观解释和方法选择。
- **易错提醒**：容易遗漏的条件、符号或适用范围。
- **必须掌握 / 建议理解 / 拓展阅读**：阅读建议，不能据此推定考试范围。
- **PPT重点 / 教材补充 / 理解补充**：区分教师材料、经核对的教材补充和自主解释。

不得编造教材页码、教师原话、课堂例题或录音时间。看不清或无法确认的内容应明确标注。资料中的疑点需要保留原内容并说明校核依据。

## 文件与阅读体验

网页保留章节导航、数学公式、图注和来源标记；PDF 用于稳定阅读与批注，Word 保留可编辑公式。正文采用清晰的蓝灰层级，强调图像可读性和必要留白。PDF/Word 沿用宋体、12.5 磅正文和约 1.3 倍行距的制作规范。

配套文件由同一份定稿整理，网页省略印刷页码。每次更新说明日期与变更范围；重新导出文件后更新目录中的校验值。
