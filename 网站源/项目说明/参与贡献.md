# 参与贡献

你可以从一处小错误开始：补齐公式的适用条件、指出图中的符号不一致、修复链接，或增加一句帮助理解的说明。

## 报告问题

每讲顶部均有“报告本讲问题”入口，也可以直接[新建笔记纠错](https://github.com/yunbianmailang/university-course-materials/issues/new?template=note-error.yml)。请提供：

- 课程和讲次。
- 网页章节链接，或 PDF 文件名与页码。
- 当前内容、疑点及建议依据。

## 提交修改

在 GitHub 上 Fork 仓库后修改对应讲义的内容源，提交 Pull Request。每讲的编辑入口指向可维护的 Markdown 源稿。新增解释需区分资料内容与理解补充，图片需说明原图或重绘。

完整的修改、构建与检查方法见[贡献指南](https://github.com/yunbianmailang/university-course-materials/blob/main/CONTRIBUTING.md)。内容规范见[笔记规范](笔记规范.md)，复用规则见[来源与许可](来源与许可.md)。
