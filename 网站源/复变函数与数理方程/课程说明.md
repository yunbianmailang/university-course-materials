# 复变函数与数理方程 · 课程说明

本课程是大二上学期课程，以数学逻辑与证明为主线：**概念动机 → 严格定义 → 定理条件 → 证明思路 → 数学推导 → 典型应用**。讲义尽量保持教师板书的实际教学主线，对抽象概念补充直观解释与几何图像，并保留完整的关键证明步骤。

## 每讲的三层结构

1. **第一层 课堂核心速览**（约1页）：核心问题、必要先修、知识结构、重要结论、课堂听讲重点，用于课前预习与课后速查。
2. **第二层 引导式学习正文**：按教师授课顺序展开的知识单元，含直观理解、严格定义、关键推导与教师课堂例题。
3. **第三层 详细参考与拓展**：完整证明与较长推导，配 **必须掌握 / 建议理解 / 拓展阅读** 优先级标识。每讲末尾附课末核心知识回顾。
