# 发布说明

## 本地发布

在仓库根目录运行：

```powershell
python 工具/构建站点.py
python -m mkdocs build --strict
python 工具/检查资料.py
python -m mkdocs gh-deploy
```

`gh-pages` 分支存放构建产物。不要手工修改该分支中的网页，下一次构建会覆盖它们。

## 自动发布

已准备 `工具/deploy-pages.disabled.yml`：对 Pull Request 自动构建和检查；main 更新通过后部署到 Pages。启用时将它放到 `.github/workflows/deploy-pages.yml`，并在仓库 Settings → Pages 中选择 GitHub Actions。

发布任务使用 `pages: write` 与 `id-token: write`，构建只需 `contents: read`。首次加入工作流需要当前 GitHub 连接具备写入 workflow 文件的权限；不需要将个人令牌写入仓库。

所有构建输入来自仓库自身；固定依赖版本见 `requirements.txt`。检查失败会停止发布。
